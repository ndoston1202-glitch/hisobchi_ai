# Fonar (hazil ilova)

Oddiy fonar ilovasiga o'xshaydi. Yoqish tugmasi bosilganda "Fonar Premium — 9 900 so'm"
oynasi chiqadi. "To'lash" bosilsa — qisqa "to'lov" animatsiyasi, keyin **"😂 HAZIL!"** va konfetti,
so'ng fonar bepul yonadi. Hazil har safar ilova ochilganda bir marta ko'rsatiladi.

Hech qanday karta ma'lumoti so'ralmaydi va hech qanday to'lov olinmaydi.
Chiroq bo'lmagan qurilmada ekranning o'zi yoritadi.

APK: GitHub **Actions → Fonar APK → Artifacts → `fonar-apk`**.

```bash
flutter test test                                  # testlar
flutter test tool/assets_test.dart --update-goldens  # ikonka va skrinshotlar
```
